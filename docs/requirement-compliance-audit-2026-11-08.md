## 3. 明确缺口清单（按优先级）

1. **微信聊天同步联动** ✅（合规路径已落地，2026-11-08 后续补齐）
   - 实现方式：**微信官方开放接口**（公众号「消息接口」被动回复 + 客服消息 / 企业微信自建应用消息），**不是外挂式接管**。
   - 核心库 `lib/core/wechat_bridge/`：签名校验（SHA1）、安全模式 AES-256-CBC 编解码（与微信规范一致）、回调路由（GET 回声验证 / POST 明文&加密 / 事件）、`PersonaChatPort` 抽象（把微信消息路由到 `ChatOrchestrator` 并写回角色会话，实现「微信↔App 日常聊天同步」）。
   - 独立部署入口 `bin/wechat_bridge_server.dart`：用户自部署为公网 HTTPS 回调（需**自有已认证微信开发者账号**）。
   - App 端配置页 `wechat_sync_settings_page.dart`（入口收进设置「更多设置」低频区）、加密偏好存储 `WeChatBridgeConfigStore`。
   - 限制（已在 UI 与文档明确）：仅响应「用户主动发给该公众号/应用」的消息，绝不读取/拦截个人微信私有数据；需用户自部署桥接服务，App 本身不内置任何违规微信模块。
2. **实时视频聊天（视频通话）** ✅ 已落地（`video_chat_page.dart`）：全屏 3D 形象 + 实时语音/文字循环，标注「模拟视频通话 · 角色为 AI」。
3. **虚拟送礼 / 虚拟互动 / 互相查看虚拟手机** ✅ 已落地（`gift_*` / `virtual_phone_*`）：礼物目录 19 项、送礼历史、虚拟手机（纯本地生成，不读取真实设备数据）。
4. **宠物 / 孩子 / 家族 完整 gameplay** ⚠️ 仅数据模型+仓库，缺养成/繁育/孕期/成长阶段/可视化族谱。
5. **剧情库小类全覆盖** ⚠️ 2861 条规模大，但按要求"每小类≥20"未达标，需补齐各小类条目。
6. **多语言"多种"** ⚠️ 仅中/英/系统三项，且页面文案未翻译。
7. **视频提取声纹** ⚠️ 声音克隆本地仅处理 wav 音频。
8. **3D 视觉精细度** ⚠️ 软渲染受限，难称"精美细腻仿真"。

## 4. 关于"模拟机测试"

- **功能缺口已补齐**：§3 中的 1–3 硬缺失项（微信合规同步 / 视频聊天 / 虚拟送礼·虚拟手机）均已实现并通过自动化测试。
- 本机具备 Android SDK / Java / emulator 目录，但 `flutter devices` 因沙箱拦截 `reg.exe` 无法枚举设备；`flutter build apk --debug` 已发起尝试，是否成功取决于原生资产（sqlite3 / llamadart 预编译库）经代理下载是否可达。
- 若模拟机启动条件具备，运行方式：
  1. 启动 Android 模拟器（或连接设备）；
  2. `flutter run` 安装并打开 App → 设置 → 更多设置 → 微信同步（合规）；
  3. 用户自部署 `bin/wechat_bridge_server.dart` 到公网 HTTPS，并在微信后台填回调；
  4. 在微信里给该公众号/应用发消息，即可与绑定角色对话（消息同步回写 App 日常聊天）。
- **当前回归基线：445 项单元/组件/端到端测试全部通过**（`flutter test`，含 17 项微信桥接协议专项：签名校验、AES 编解码往返、明文/加密回调、事件、配置序列化；**另含 2 项「真实端口」端到端同步测试** `test/wechat_sync_e2e_test.dart`：GET 回声验证、POST 微信文本→角色回复发回微信 + 写回 App 加密库单聊会话，证明"微信发言已真正同步回 App"），`flutter analyze --fatal-infos` 零问题。属代码级 + 协议级 + 端到端回归；真机/模拟机集成测试需用户侧具备微信开发者账号与公网部署。
