This directory holds offline sample GLBs for Route C (text-to-3D).
Generated by tools/text_to_3d/generate.py (Shap-E) on a networked machine,
then committed here so the app can demo 3D without a local server or network.
Expected files (ids match lib/core/avatar3d/route_c_glb_store.dart):
  cat.glb  dog.glb  dragon.glb  robot.glb  chair.glb  flower.glb
Until they exist, the in-app 'offline samples' will show a load error;
live generation via the local server still works once Shap-E weights are cached.
